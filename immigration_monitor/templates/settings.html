Schedule & notifications

Monitoring requires a running, connected computer. Sleep or power-off prevents ordinary checks. One catch-up check runs after a missed interval; intermediate changes cannot be reconstructed. Detection of every policy update is not guaranteed.

Run without the browser

After Windows setup, opt in using scripts\install-scheduler.ps1. It runs the independent checker every 15 minutes to check due sources (six-hour default) and prepare the daily digest near your selected time. Use scripts\remove-scheduler.ps1 to remove the task.

Launch the UI separately using Launch.cmd. Closing the browser does not stop a configured scheduled checker. The default task runs only while your Windows user is logged in.
